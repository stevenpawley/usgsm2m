# USGSm2m: R Interface to the USGS/EROS Machine-to-Machine (M2M) Application Programming Interface (API)

The USGS/EROS Machine-to-Machine (M2M) Application Programming Interface
(API) provides a method of searching and acquiring data from the
USGS/EROS data inventories. The M2M API provides the same options and
functions as EarthExplorer (EE) including searching for data collections
and imagery, requesting metadata, and accessing all datasets in the EE
catalog. Note that this package is not affiliated with the USGS/EROS,
but is a community-developed interface to the M2M API for use in R.
